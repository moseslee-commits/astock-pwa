# A股智能选股系统

五维共振选股体系 · 实时行情 · 智能选股 · 持仓管理 · 价格预警

## 功能特性

- 实时看板：81只龙头股实时行情、五维评分、板块资金流向
- 智能选股：五维共振多条件筛选、策略模板、选股结果保存
- 持仓管理：添加/卖出持仓、实时盈亏、资产分布、交易记录
- 价格预警：突破/跌破预警、自动检查、触发提醒
- 选股历史：历史记录回溯、入选趋势、高频统计、导出CSV

## 移动端访问

PWA应用，支持添加到手机主屏幕：

**访问地址**: https://moseslee-commits.github.io/astock-pwa/mobile.html

### 安卓安装
1. 用Chrome打开上面的地址
2. 点击菜单 → 添加到主屏幕 / 安装应用
3. 桌面出现图标，点击全屏运行

### iOS安装
1. 用Safari打开地址
2. 点击分享 → 添加到主屏幕
3. 点击添加

## 技术栈

- 纯HTML/CSS/JavaScript，无需后端
- 东方财富公开API获取行情数据
- localStorage本地数据存储
- Service Worker离线缓存
- PWA渐进式Web应用
